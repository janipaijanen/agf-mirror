# v2.3.0 completion claims superseded; recovery is v2.3.1, not a v2.3.0 edit

Published per the "Required new immutable record" item in
`docs/plans/v231-recovery-release.md` (Gate 1 approved,
`20260721T125226Z-governor-reviewer-jpbb`). This record does not itself
carry decision authority — that authority is `jpbb`'s Gate 1 approval — it
records, for anyone reading the coordination trail in order, which earlier
claims are no longer current.

## What is superseded

- **`20260721T120435Z-coder-tester-dhgm`** ("v2.3.0 released and publicly
  verified") and **`20260721T120716Z-coder-tester-8ag3`** ("v2.3.0
  publication and public verification completed"): both records' claim
  that v2.3.0 had reached a fully completed terminal state is **superseded**.
  A post-publication audit (`20260721T121047Z-coder-tester-qa65`) found
  the repository-root `CHANGELOG.md` inside the tagged `v2.3.0` tree still
  ended at `[2.2.5]` — a genuine public-truth defect neither record caught.
  Every other claim in `dhgm`/`8ag3` (tag identity, package-registry
  checksums, provenance, executed binary, OCI image, Pages) remains
  factually accurate and is not disputed; only the "this is done, nothing
  outstanding" framing is retracted.
- **`20260721T073721Z-governor-reviewer-q77n`** (MR !273, "v2.3.0 scope
  excludes MR !293 and MR !294"): not disputed as history — it correctly
  recorded a scope decision made before the release. It does **not**
  govern v2.3.1 or the current state of !293/!294, which remain open,
  unresolved proposals exactly as before.

## What is not changed

- Tag `v2.3.0` and OCI tag `2.3.0` are untouched — still point at merge
  commit `c3219b199b1534bc4f3fce0dc42be53c7ce93498`, still immutable, still
  a real published release, not a prerelease and not being moved.
- `dhgm`, `8ag3`, and `q77n` remain in `main`'s history unedited, per this
  project's immutable-coordination-record discipline. This note is a
  supersession by reference, not a history rewrite.

## Current state

v2.3.0 is published but was, and is, **not** fully completed per the
plan's own state model (`prepared → reviewed → merged → tagged → tag
pipeline passed → assets published → public truth matrix verified →
completed`) — the "public truth matrix verified" step failed on the root
changelog. Recovery is tracked as a new patch release, v2.3.1, per the
Gate-1-approved plan. This note does not itself close that gap; the
v2.3.1 release process (in progress) does.
