# Superseding Gate 2 handoff: all 9 BLOCK findings corrected

MR !351, current head. Corrected each finding from `msha` with real
verification, not just unit fixtures where a real check was feasible:

1. **Legacy classification too permissive** — `validate_record` now
   classifies against a dedicated `release-provenance-legacy.schema.json`,
   built from the actual published v2.3.1 framework and tooling records
   (fetched from the real GitLab package registry, not approximated).
   Arbitrary JSON, an explicit unsupported `schema_version`, and near-miss
   malformed legacy shapes are `AssuranceLevel::Invalid`. Commit `e490adc`.
2. **Post-publication lifecycle absent** — new `agov dist
   post-publication-check --releases-url <api-url> --download-dir <dir>`
   anonymously discovers and downloads every asset linked from a real
   GitLab Release, then validates against the downloaded bytes. **Run for
   real against the actual published v2.3.1 release**: discovered and
   downloaded all 15 real assets, correctly classified all 4 real legacy
   records with zero findings, exit 0. That same real-data run surfaced
   and let me fix a genuine bug in the bijection check (see #6). Commit
   `5c8f8e3`.
3. **Executable self-report agreement absent** — new
   `extract_from_tar_gz`/`extract_from_zip` + `run_self_report` +
   `check_self_report_agreement` (exact version match, prefix-tolerant
   commit match, absolute `dirty: false` requirement) and `agov dist
   self-report-check`. Verified against the real compiled `agov` binary:
   packed a real dirty local build into a real tar.gz, correctly rejected
   for `dirty: true` (accurate — the tree had real uncommitted changes);
   rebuilt clean with a fake commit, repacked, confirmed the positive case
   passes. Commit `d9c8b58`.
4. **OCI label agreement tautological** — replaced `check_label_agreement`
   (compared a record's own `labels` to its own `version`/`source_commit`
   — both written by the same call, so it could never disagree) with
   `check_oci_image_evidence`, which takes real evidence obtained via
   `podman inspect` (new `--oci-image` flag, shells to podman matching
   this project's existing convention). Verified against a real locally
   built image from the actual `Containerfile.agov`: a record with
   internally-consistent-but-fabricated labels was rejected by real
   evidence; a record with a fabricated digest was rejected; the correct
   case passed. Commit `62a73cc`.
5. **Generators/CI don't validate generated provenance** — both
   `emit_provenance_record` (CLI) and `dist::write_provenance` now call
   `validate_record` and refuse to write an invalid record. Verified: a
   deliberately wrong product/packaging combination is now rejected before
   any file is written. `release:create` now extracts `agov` from the
   already-built musl tooling archive and runs `agov dist
   validate-provenance dist/*-provenance.json --artifact-dir dist` against
   the complete assembled set before any upload. Commit `87aafbd`.
6. **Cardinality not enforced as a bijection** — new
   `check_primary_artifact_coverage` (every primary artifact in
   `--artifact-dir` has exactly one record; every record names a real
   artifact — catches missing, omitted, and stale/extra records) and
   `check_no_duplicate_oci_identity`. The real v2.3.1 post-publication run
   (#2) surfaced a genuine bug here: the coverage check filtered on
   `artifact_kind == "file"`, a field legacy records don't have, so every
   real artifact was false-flagged as having no record. Fixed: bijection
   is a v2.4 contract guarantee, never retroactively imposed — a batch
   with no `schema_version: "2.4"` record returns no coverage findings.
   Commits `696d43b`, `5c8f8e3`.
7. **`target_platform` optional for tooling** — schema now enforces a
   closed subtype via `if`/`then`: `packaging: manifest-source-archive`
   requires `product: agf` and forbids `target_platform`;
   `packaging: tar.gz`/`zip` requires `product: agov` and requires
   `target_platform`. Wrong combinations rejected. Commit `e490adc`.
8. **`artifact_filename` path traversal** — schema pattern requires an
   alphanumeric first character (structurally excludes `.`/`..`) and no
   slashes; `check_artifact_agreement` independently rejects any separator
   or `.`/`..` before ever joining to `artifact_dir`, so a malicious or
   malformed filename cannot escape. Treated as highest priority (real
   security defect). Commit `e490adc`.
9. **Checksum sidecars optional/weakly parsed** — sidecar is now mandatory
   (missing = finding, not silent skip); strict GNU-coreutils-format
   parsing (`<64-hex><space><mode><filename>`) rejects multiple entries,
   malformed delimiters, and a correct hash paired with the wrong
   filename. Commit `e490adc`.
