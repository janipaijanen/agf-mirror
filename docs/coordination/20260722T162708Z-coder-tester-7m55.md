# Post-Workstream-D reassessment of the marketing/visual-semantics audit scope

`kprg` asked that `qj7s`'s reviewer-C assessment be re-run against the
*post-Workstream-D* figures before finalizing the post-release
visual-semantics plan's scope, since several cited defects might already
be closed. Workstream D's `gate-pipeline` conversion + palette contract
(MR !395) merged to `main` at `2587eb1`. Re-checked every BLOCK item
`qj7s` raised against the current tree, per-figure, directly (not from
either prior report):

## BLOCK 5 — legends naming shapes they never draw ("(oval shape)"/"(diamond shape)")

`qj7s` cited 6 files. Current tree:

- `gate-pipeline.dot` — **closed**. The literal legend text is gone; the
  shape key now renders real ellipse/diamond/rounded-box/double-border-box/
  dashed-box swatches instead of describing shapes in words.
- `coordination-channel.dot`, `evidence-lifecycle.dot`,
  `governance-loop.dot`, `learning-loop.dot`,
  `operating-responsibility-map.dot` — **still open**, unchanged (grep
  confirms the literal `(oval shape)`/`(diamond shape)` text is still
  present in all five).

## BLOCK 6 — white text on amber/green/grey fails WCAG AA

`qj7s` cited 7 files (including `docs-audience-map`, since removed in a
separate Workstream D slice). Current tree:

- `gate-pipeline.dot` — **closed**. All amber/green node text now uses
  `#1A1A1A` (~6.03:1 / ~4.67:1, both clear 4.5:1 AA normal-text); a
  mechanical regression (`agf/docs/build/hooks/check_palette_contrast.py`,
  wired into CI) now guards this figure against reintroduction.
- `docs-audience-map.dot` — **closed by removal** (separate Workstream D
  Class 1 slice, MR !388).
- `governance-loop.dot`, `evidence-lifecycle.dot`,
  `operating-responsibility-map.dot`, `coordination-channel.dot`,
  `adoption-exit-flow.dot`, `learning-loop.dot` — **still open**, unchanged
  (grep confirms `fontcolor=white` still paired with amber/green/grey
  fills in all six).

## BLOCK 7 — one colour, incompatible meanings across figures (amber)

**Partially addressed.** The semantic responsibility palette contract
(`palette.md`) now exists and fixes amber's meaning to "Human decision"
project-wide; `gate-pipeline.dot` conforms to it. The other six
unconverted figures still assign amber per their own pre-contract,
figure-local convention (e.g. `evidence-lifecycle.dot` still uses amber
for "Incident / Observation"), so the cross-figure inconsistency
persists everywhere except `gate-pipeline` until each figure converts.

## BLOCK 8 — figure terminology contradicts the canonical page

**Still open, unchanged.** `adoption-exit-flow.dot` still labels its
three exit nodes Freeze / Replace on update / Decommission;
`exit-and-decommission.md` still defines the canonical three modes as
Pause / Downgrade / Remove. Workstream D has not touched this figure.

## Net effect on scope

One of eight figures (`gate-pipeline`) is now fully converted; one
(`docs-audience-map`) is removed. Six remain exactly as `qj7s`
described them: `governance-loop`, `evidence-lifecycle`,
`coordination-channel`, `learning-loop`, `operating-responsibility-map`,
`adoption-exit-flow`. The palette contract itself — the artifact `qj7s`'s
reviewer C recommended scoping the "narrower first phase" around — now
exists and has one proven conversion behind it (three Gate 2 review
rounds, independently re-verified each time), which is direct evidence
for `qj7s`'s recommended two-namespace, narrower-phase approach over
`1a7k`'s four-namespace DSL: the contract itself was sufficient to close
BLOCK 5/6/7 for one figure without any of `1a7k`'s proposed icon
catalogue, screenshot matrix, or additional namespaces.

No implementation taken here — this is the requested reassessment only,
to inform whoever drafts the post-release visual-semantics plan's Gate 1
submission. MR !354 (consolidated findings) remains open and accurate as
prior-state evidence; this record narrows what's actually left.
