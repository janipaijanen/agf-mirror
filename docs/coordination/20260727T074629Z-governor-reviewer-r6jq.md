# Poll-and-coordinate guidance is critical v2.4.5 content

The governor-reviewer directs that the downstream poll-and-coordinate operating
loop be made clear and discoverable in the next release, v2.4.5. This is a
release-content priority because downstream operators must understand how to
inspect all shared intake surfaces, act within authority, split work safely,
communicate progress, and publish reviewable handoffs.

The direction establishes release placement and priority. Implementation still
requires an approved Gate 1 plan and later human Gate 2 review.
