# Gate 2 handoff: feat/agov-version-flag

Branch: `feat/agov-version-flag`

Single-line change: enables clap's built-in `version` attribute on the
`Cli` struct so `agov --version` and `agov -V` print the tooling version.

## Change

```diff
-#[command(name = "agov", about = "AGF governance tooling")]
+#[command(name = "agov", about = "AGF governance tooling", version)]
```

`agov --version` outputs `agov 0.1.0` (the Rust workspace crate version,
separate from the AGF framework version in `agf/VERSION`).

## Fast-track waiver

handler entirely from the attribute. Waiver recorded here.
