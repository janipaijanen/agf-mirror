# Gate 2 handoff: AGF nutshell flyer brought into the repo

Implements `docs/plans/agf-nutshell-flyer-in-repo.md` (approved in chat by
the human governor when selecting the CI-generation approach).

## Summary

- New source: `agf/docs/figures/src/agf-nutshell-flyer/` (`build_flyer.py`,
  `template.html`, `fonts/*.b64`) — same source-committed convention as the
  Graphviz `.dot` diagrams.
- New rendered output (dual-copy convention): `agf/docs/figures/
  agf-nutshell-flyer.png` and the byte-identical `agf/docs/site/reference/
  figures/agf-nutshell-flyer.png`.
- New CI job `agf:flyer:verify` (path-scoped to the flyer source, the two
  committed PNGs, and `agf/VERSION`; runs on MR/branch/tag, mirroring
  `agf:dist:validate`'s rule shape). Verified locally end-to-end before
  writing the job (script logic, not just the YAML). Hard-fails on a
  generator error, on the two committed copies diverging, or on rendered
  dimensions differing from the committed PNG (catches structural
  regressions); prints an advisory, non-blocking note if only the content
  hash differs, since a headless-browser PNG encode is not guaranteed
  byte-identical across Chromium versions — a hard pixel-diff gate would be
  flaky, not meaningful.
- README.md and `agf/docs/site/docs/index.md` (the docs site's first page)
  both now embed the PNG.
- Content fixes folded in per direct governor feedback during this session:
  removed "for engineering students" and "(the student)", "front of a
  professor" → "front of a customer", spelled out "Agent Governance
  Framework" in the masthead, added a provenance line (`AGF vX.Y.Z ·
  generated DATE`, both parameterized from `agf/VERSION` and build date —
  not hardcoded), corrected the license footer to the canonical dual-license
  phrasing already used at `agf/docs/site/index.md` (previously understated
  as CC BY-SA 4.0 only), and added an explicit clarifying line after the
  hero stating AGF is not an AI model/LLM/coding assistant itself, naming
  real compatible tools (Claude, Codex) — a real misconception risk the
  "Your AI assistant" framing invited.

## Not yet CI-verified end to end

The `agf:flyer:verify` job's shell logic was dry-run locally (chromium +
the exact Python verification block), but the `apt-get install chromium`
step inside the `python:3.14-slim` CI image itself has not been observed
to actually succeed in a real GitLab CI run yet — this is a genuinely new
CI dependency for this repo. Please treat this MR's own pipeline result as
part of Gate 2 evidence, not just the local dry-run.

- `agf:flyer:verify`'s script logic dry-run locally: dimensions and content
