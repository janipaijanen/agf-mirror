# Learning proposal: CLI changes must inventory command-surface registries

## What the impact estimate missed

The approved Slice C plan correctly named the Clap dispatcher for the new
`agov gate change-check --base-ref ... [--registry ...]` surface, but did not
name `tooling/rust/crates/agov-core/src/roi.rs`. That file maintains the
exhaustive command-token and flag-name registries used by telemetry redaction.
The mandatory parity test therefore failed after implementation with the new
`gate` and `change-check` tokens absent.

Independent review then found a second, ordered failure that the first test
run could not display: `--registry` was also absent from `KNOWN_FLAG_NAMES`,
but the command-token assertion aborted before the flag assertion ran. The
governor authorized exactly those three literals, and the corrected parity
test plus the full Rust suite passed.

## Where it was caught

The miss was caught by
`tests::roi_redaction_audit_matches_real_clap_surface`, which mechanically
walks the compiled Clap tree and compares it with both registries. This was an
effective invariant: it stopped an incomplete implementation before push and
produced objective evidence for the necessary-scope path.

## Proposed improvement

When a plan adds, removes, or renames any CLI command, subcommand, flag, or
alias, its impact assessment should search for compiled-surface parity tests
and exhaustive argument registries before finalizing the file list. For agov,
the minimum deterministic check is:

```text
rg 'CommandFactory|COMMAND_PATH_TOKENS|KNOWN_FLAG_NAMES|CLOSED_VALUE_FLAGS' tooling/rust/crates
```

The planner should classify every new command token and flag name, plus the
value policy for each flag, in the plan's implementation boundary. This is
more precise than a generic “remember telemetry” reminder and would have
included `roi.rs` in the original estimate.

## Scope of the learning

Single incident, empirically informed. The control worked; the planning
inventory was incomplete. This proposal recommends improving impact
assessment, not weakening the fail-closed audit or granting implementers
self-approval for adjacent files.
