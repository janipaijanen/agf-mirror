# Gate 2 handoff: three-minute entry docs

Branch: `docs/three-minute-entry`

## Summary

This docs-only change incorporates the Lumo external review note about a CTO
having roughly three minutes to understand whether a repository is worth deeper
evaluation.

Changes:

- Rewrite the top of `README.md` from taxonomy-first framing to a problem-first
  three-minute entry: AI changes can become hard to reconstruct from git
  history alone.
- Add the same problem/mechanism/cost/exit shape to the docs homepage.
- Add a compact homepage Mermaid flow showing plan approval, implementation
  with CI evidence, merge approval, and merge.
- Rename the README's deeper path from "Five-minute path" to
  "Twenty-minute path" so the first scan and the follow-up evaluation are
  distinct.

Critical handling:

- The text says "git history alone" rather than blaming git. The gap is missing
  delegation, intent, and approval context, not version control itself.
- The exit wording is bounded to "a small default install" and avoids promising
  that every customized adoption can always be removed in one commit.
- The diagram is intentionally not the full governance model; it is the
  first-scan explanation of where human gates sit around AI work.
