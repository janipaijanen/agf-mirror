# Part 1 trial blocked by destination runner capability

Scope: approved Part 1 CI routing trial in draft MR !3102 at
`1fc1ea4a312328975b53b2b98d12e118797af162`.
Recommendation: BLOCK Gate 2; the approved plan's premise that these jobs
can simply be re-tagged to the Podman pool is disproven for the current
runner configuration.

Exact-head MR pipeline `2973946004`, job `17363974927`
(`agov:oci:mr-build-scan`) ran on online project runner `55908035`.
The job successfully used Podman to build the unpublished image, then
tried to launch the pinned Trivy scanner container and failed:

```text
Error: crun: mount `proc` to `proc`: Operation not permitted: OCI permission denied
ERROR: Job failed: exit code 126
```

The job never scanned the deliberately vulnerable pinned Alpine image,
so the failed pipeline is **not** evidence that the HIGH/CRITICAL
vulnerability gate still fires. The same nested `podman run` command is
in the job's normal `scan-unpublished` path; removing the fixture cannot
make this runner capable of executing it. `rust:tooling:oci-pull-test` and
release verification also require real Podman pull/run operations, so
there is no evidence that re-tagging all four jobs would work. The MR
was marked Draft with the blocker stated in its description. No
corrected acceptance run was started merely to seek green status.

Local routing regression tests all passed (15), showing CI configuration
consistency but not runner execution. A local Trivy 0.66.0 scan of the
same pinned Alpine digest did exit 1 with 15 fixable HIGH/CRITICAL
findings; the CI runner did not reach that scan. The distinction matters
for gate-self-test evidence.

The current plan does not authorize changing runner privileges, widening
CI job images/scripts to use an in-container scanner binary, redesigning
OCI pull evidence, or routing these jobs to another runner. These are
material scope and security choices. Governor-reviewer: decide a new
bounded plan/assignment for a verified OCI-capable execution path or
restore the DinD runner before Part 1 is retried. Until that decision,
keep the four jobs' main-branch routing unchanged and do not merge
MR !3102. The Windows migration is independently stopped by failed
Phase B2 evidence in MR !3103 / coordination record `hqbq`.
