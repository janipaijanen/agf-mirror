# Codex response: v1.x docs review findings

I reviewed the planner note, v1.x public docs pages for Position,
Contribute, Evidence, and Bibliography, and the current v2 docs tree after
MR !184.

## Priority revision

MR !184 already implements the highest-priority position/runtime page. I
would revise the remaining priority order as:

1. **Contribute / upstream guide** — now the highest missing item. v2 has
   upstream-learning mechanics in the FAQ, but not the v1.x three-path
   contribution model: submit a learning, propose a rule, propose an agent.
2. **Bibliography** — medium priority. v2 cites theoretical sources in rules
   and docs, but lacks a reader-facing reference page.
3. **Failure modes / "why this exists" framing** — medium-low. Add named
   failure modes to an existing entry page rather than creating a standalone
   page unless the governor wants an evaluator-focused motivation page.
4. **Full role taxonomy figure** — low. Useful, but `agf/agents/MANIFEST.yaml`
   and role YAML files remain authoritative.
5. **Status / transparency page** — defer unless generated. A manually
   maintained status page is likely to rot.

The position page can remain in the high-value bucket, but it is no longer a
missing high-priority item after MR !184.

## Position page structure

- AGF and agent runtimes
- Concrete relationship
- Per-tool notes
- Claude Code

Optional follow-up sections, if scope allows:

  and ML governance.
- Evidence status by runtime — explicit evidence maturity for Claude Code vs
  non-Claude runtimes.
- When not to use AGF — short runtime-category-specific non-use cases.

## Contribute page assessment

I recommend a dedicated Contribute page rather than extending
`evidence-and-learnings.md`.

`evidence-and-learnings.md` should stay focused on the evidence model:
learning records, ownership, thresholds, and anonymization. A Contribute page
has a different job: tell an adopter what to do when they want to send
evidence upstream. The v1.x three-path structure is still useful:

- Submit a learning.
- Propose a rule.
- Propose an agent.

That page should include evidence thresholds and the higher bar for new agents.
It can link back to Evidence and learnings for the model behind those
thresholds.
