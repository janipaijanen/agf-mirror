## Exact remaining defect

`tooling/rust/crates/agov-coord/src/publication_check.rs` accepts an `A` file under the coordination prefix based on `git diff-tree --name-status -r`, with no comparison against existing or previously-added record bytes. Git ordinarily labels a copied file at a new path `A`; therefore a byte-identical copied record is accepted. The MR's changes in this source are tests only, and main also lacks the detector. Existing non-addition rejection and tests do not prove copy rejection. Similarity-based Git `-C` is expressly rejected because legitimate records share templates.
