# Fix homepage terminology drift: "assistant" (general) vs "agent" (governed role)

User-requested check: the live homepage used four different bare terms for
the same concept — "AI coding agents", "AI assistant"/"assistant", "AI
agents"/"AI agent", "coding tools" — with no canonical-descriptor table
anywhere in the docs to standardize against (`marketing-tone-rule.md`'s
"Message integrity" section asks for one; none existed for this concept).

Standardized on a two-term split rather than collapsing to one term,
because the page genuinely uses the concept two ways:

- **"AI assistant"** — the general concept, the tool acting for the user.
  Used everywhere the sentence doesn't depend on this framework's own
  role/gate vocabulary (the opening hook, the adoption steps, the
  git-native-operation and token-savings sections).
- **"agent"** — reserved for a role acting under this framework's gate
  model (implementer, reviewer, "an agent cannot approve its own work").
  Left unchanged in the "Roles" bullet and "Accountability structure for
  AI agents" section, where the term is being formally introduced/used
  with its framework-specific meaning.

Seven sentences changed (line numbers as of this diff): the opening hook
("AI coding agents" → "AI assistants"), the Step 2 rule-review sentence
("trains agents" → "trains assistants"), the git-native-operation sentence
("different coding tools" → "different assistants", dropping a third
synonym), the token-savings opening sentence ("AI agent reads coordination
files" → "AI assistant reads coordination files", since that sentence
describes generic mechanical action, not gate-model role separation), and
three more caught by the user's follow-up question ("is assistant or AI
assistant?"): the page was also inconsistent about the "AI" prefix itself,
independent of the agent-vs-assistant split. Settled on: "AI assistant" on
first mention within each H2 section, bare "assistant" as short form for
repeat mentions in that same section — normal technical-writing style, not
a new rule. Fixed three sections whose first in-section mention was bare
("Assistants coordinate..." in How it works, "one assistant fills all
roles" in What you get, "assistants can follow" in Who benefits) to lead
with "AI assistant(s)".

Scope: homepage (`agf/docs/site/index.md`) only, per what was actually
asked. A fuller site-wide terminology audit against a written canonical-
descriptor table is a larger, separate task not attempted here.
