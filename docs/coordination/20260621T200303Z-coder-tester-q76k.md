# Gate 2 handoff: adopter FAQ ADR discipline

## Summary

Adds a new question to the adopter FAQ:

```text
How do ADRs fit with AGF?
```

The answer tells downstream adopters to keep Architecture Decision Records and
incorporate them into the governed loop rather than replacing them with
coordination messages. It recommends:

- using ADRs for durable architecture choices;
- using coordination messages for the work trail and gate decisions;
- creating a local `docs/adr/` directory from the shipped ADR template pattern;
- referencing relevant ADRs from Gate 1 plans;
- involving affected humans or agents before ADR acceptance;
- checking implementation alignment at Gate 2;
- superseding ADRs with new records instead of rewriting accepted history.
