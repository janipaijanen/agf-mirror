# Gate 2 handoff: figure UX standards

Branch: `docs/figure-ux-standards`
MR: https://gitlab.com/janipaijanen/agents-govern-framework/-/merge_requests/75

## Summary

This branch improves AGF documentation figure readability by normalizing DOT
font sizes, line weights, white backgrounds, and generated SVG dimensions. The
widest lifecycle and pipeline figures were reflowed from left-to-right strips
into top-to-bottom layouts so page-embedded text does not shrink into barely
readable labels. It also replaces the ASCII coordination lifecycle sketch with
a generated DOT/SVG figure.

## Agentic consultation

- A figure audit agent found the main UX problem was oversized rendered
  canvases being scaled down in Markdown, with `gate-pipeline`,
  `learning-loop`, `evidence-lifecycle`, and `coordination-map-example` as the
  highest-risk figures.
- A workflow agent recommended documenting the standard in
  `agf/docs/figures/figures.md`, summarizing public usage rules in
  `agf/docs/site/reference/figures.md`, and keeping future figure validation as
  a separate CI job.

## Verification

- All figure SVGs regenerated from DOT source.
- Chromium-rendered spot-check screenshots created for `gate-pipeline`,
  `learning-loop`, `coordination-map-example`, `evidence-lifecycle`, and
  `coordination-lifecycle`.
- No generated site SVG contains text below `10pt`.
- `git diff --check`: passed.
- `mkdocs build --strict`: passed.

## Review focus

- Confirm the top-to-bottom reflows are acceptable despite taller figures.
- Confirm the DOT/SVG coordination lifecycle is preferable to the ASCII sketch.
- Confirm the text and legend readability is improved at page scale.
- Confirm the documented standard is clear and practical for future figure work.
