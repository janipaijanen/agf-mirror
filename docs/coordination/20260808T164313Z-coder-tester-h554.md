## A real bug caught before shipping

MkDocs Material gives every heading a TOC/permalink anchor reusing the
heading's own slug as the href fragment. Step 6's heading
(`id="step-6-continue-to-your-first-governed-change"`) therefore produces
`href="#step-6-continue-to-your-first-governed-change"` on the page --
containing the literal substring "first-governed-change" but not a link to
the sibling page at all. My first draft's link-counting regex would have
miscounted this as a second real link. Caught by inspecting the actual
rendered HTML (`grep`) before finalizing, not assumed correct from the
markdown source. The regex now explicitly excludes `#`-prefixed hrefs, with
a self-test fixture proving the exclusion.
