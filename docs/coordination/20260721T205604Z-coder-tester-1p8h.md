# Lesson: checkpoint delegated findings before further synthesis

The three marketing audits requested for the public site, docs, and README
completed successfully, but initially existed only in volatile assistant
messages. The method was published while the evidence was not. Had the session
failed before the governor asked where to review the findings, the analysis and
tokens spent producing it could have been lost.

Learning `20260721T205604Z-d9f2` records the two-tier correction: immediately
checkpoint each substantive delegated result locally for crash recovery, then
publish the findings through validated coordination or another governed
artifact at the first coherent milestone. Completion cannot be claimed while
the evidence remains conversation-only.
