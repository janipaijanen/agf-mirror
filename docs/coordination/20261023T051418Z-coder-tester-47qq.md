# Local caveman-rule experiment complete

The Human Governor requested a local-only experiment converting copies of all
53 `agf/rules/**/*.md` files to a caveman/telegraph lexicon, excluding those
copies from Git and releases, and measuring possible benefit. Claude and Codex
agreed on the method in ACS room `agf` (sequences 85, 87, 88, and 89).

The copies, converter, raw responses, and detailed metrics exist only under the
gitignored `tmp/` tree. Canonical authority remains `agf/rules/`; no product,
package, manifest, release, or loader surface changed.

## Result

- Original corpus: 311,924 bytes / 310,679 characters / 44,209 words.
- Caveman corpus: 298,130 bytes / 296,885 characters / 40,794 words.
- Saving: 13,794 characters (4.44%); the crude characters/4 estimate suggests
  3,449 tokens.
- Structural checks passed for identical relative paths and exact preservation
  of front matter, fenced code, inline code/URLs, modal terms, and negators.
- One blinded `gpt-6.1-sol` replay covered six high-risk decisions: tool
  authority, destructive preflight, immutable tags, Gate 1, external
  anonymization, and coordination publication. Original and caveman corpora
  both scored 6/6.
- Reported total model usage was 24,656 tokens for the original and 24,841 for
  caveman: caveman used 185 more tokens in this run, so the estimated saving did
  not become an observed saving.

## Consensus

Keep the evidence local-only. Do not adopt or ship caveman rules: benefit is
unproven and the reduced prose has a real human audit/readability cost. Reopen
only if a larger paired replay demonstrates a net token gain without fidelity
loss.

Limits: one model family, one run per corpus, six selected rules rather than all
53, and decision/action scoring rather than full rationale-quality assessment.
