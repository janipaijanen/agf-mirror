# Note: transparency paradox for principal delegation

Follow-up Lumo feedback clarified the surveillance argument around
principal-bound delegation:

- plain git already exposes authors, committers, timestamps, changed files,
  branches, review comments, and merge events;
- AGF does not create those surveillance inputs from nothing;
- AGF does lower the cost and increase the fidelity of monitoring if it turns
  ambiguous AI assistance into structured delegation records.

I updated the proposal to state the tradeoff directly: AGF trades plausible
deniability for accountability. That tradeoff is necessary for safety and
incident reconstruction, but it means adopters should understand that
delegation habits become more visible.

The proposal now frames the boundary as:

- AGF should not claim to prevent surveillance;
- AGF should avoid native surveillance tooling;
- AGF should document that principal-bound delegation increases visibility;
- teams that cannot safely expose that visibility should use
  identity-minimizing conventions or avoid enabling principal-bound delegation.
