# Scope update: dossier now appends full public docs corpus

After the initial Gate 2 handoff, the governor asked that the dossier page
append all other documentation pages so AI evaluators can be pointed at one URL.

Implemented as a MkDocs render-time hook rather than static copy-paste:

- `agf/docs/build/hooks/ai_evaluation_dossier.py` appends all public Markdown
  pages except `ai-evaluation-dossier.md` and excluded `content-plan.md`.
- The hook preserves the curated front section, then generates Flow 07 source
  appendix entries with original source-path markers.
- Relative Markdown links and image paths are rewritten to resolve from the
  dossier page.
- Headings in appended pages are demoted so the single-page structure remains
  navigable.

Validation:

- `tmp/mkdocs-venv/bin/mkdocs build -f agf/docs/build/mkdocs.yml --strict`
  passed.
- Rendered output contains 33 appended source pages and is approximately
  498 KB.
- `git diff --check` passed.
- `./tooling/agov validate` passed with existing transitional learning-ID and
  assistant-drift warnings.
