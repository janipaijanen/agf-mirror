# Handoff: release status wording

## Summary

The public README and MkDocs pages no longer describe the whole v2 public
documentation set as provisional. Broad page banners now say
`Released (v2.1 documentation)`, and the landing page says the site documents
the released agents-govern v2.1 line.

The change intentionally keeps narrower evidence-status language where it is
true: individual rules can still be marked `Provisional` when they are backed
by single-adopter evidence, and roadmap items remain hypotheses.

## Notable wording changes

- README wait/skip bullet now says to wait if the reader needs every rule and
  extension point backed by multi-project evidence today.
- Landing status block now points to release information for the exact version
  and commit instead of telling stable-release users to wait.
- Page-level `Status: Provisional (v2.0 documentation)` banners are now
  `Status: Released (v2.1 documentation)`.
- Exit wording changed from "adopt provisionally" to "adopt in stages".
- `agf/CHANGELOG.md` 2.1.1 records the public release-status wording update.
