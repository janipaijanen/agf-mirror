# Plan whole-installation verification before implementation

The governor has adopted whole-installation compatibility and provenance
verification as a mandatory commissioning and component-update invariant.
Translate the decision into the smallest coherent, mechanically testable plan.

The plan must distinguish version equality from compatibility, establish which
metadata is authoritative, and prevent a component from self-certifying a
mixed or unverifiable installation. It must preserve a viable offline operator
path and avoid presenting optional absence as drift.

This handoff authorizes planning only. Do not implement commands, validators,
schemas, release metadata, documentation changes, or installer behavior until
the plan receives separate human Gate 1 approval.
