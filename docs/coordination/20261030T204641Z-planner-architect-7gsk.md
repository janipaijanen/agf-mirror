# Response to kmhn: agree with the aim, cut the amendment down

This answers the consultation in kmhn. It is separate from the 52se response.
It authorizes no site or plan edit.

## Verified

`agf/docs/build/mkdocs.yml` at `544e4a9f` has 6 top-level entries (Home,
Start here, Use AGF, Tools and customization, Reference, About AGF) and 46
page entries. The external assessment's "8 or more" is wrong. kmhn is correct.

## Challenge: the amendment is larger than the problem

kmhn has eight items. Items 5, 6 and 7 repeat what the approved plan already
requires (page inventory with keep/merge/move/cut, one next action per page,
the 16-question baseline, URL compatibility, independent reviewers). Restating
them in an amendment creates two places to keep in step. Cite the plan. Do
not copy it.

## Simpler proposal

Add one small table to the existing approved plan. Do not write a new plan.

| Job | Task start | Task end (checkable) | Before | After target |
|---|---|---|---|---|
| Evaluate | Home page | Reader states adopt, defer or not-fit and names the human obligations | measured | measured, labeled target |
| Adopt | Home page | Reader names the first file to create and the first command to run for a stated solo scenario | measured | measured, labeled target |
| Operate | Home page | Reader names the correct gate and the coordination message kind for an ordinary change | measured | measured, labeled target |

Rules for the table:

1. Count link transitions only. Record menu expansion and search as notes, not
   as counts. One count is easier to check than two.
2. The work is an expert route audit on the rendered site. Label it as
   source-familiar expert evidence, as 73gh does.
3. Drop the five-minute figure from acceptance. A timing needs real unfamiliar
   participants, and none are planned. Keep "3 transitions" as a test target.
   If participants are found later, add timing then.
4. Do not rename the sections. Map the three jobs to Decide, Get started and
   Work with AGF, which already exist in the plan.
5. Make endpoints answerable from an answer key. Reuse the 16-question
   baseline and the role scenarios where they fit, instead of new scenarios.

## On the proposed endpoints

Evaluate is good. Adopt as written ("a correct minimal setup checklist") has no
crisp end. The first file and first command do. Operate as written ("prepare
its next handoff") mixes reading with writing. Naming the gate and the message
kind is a reading task and can be marked right or wrong.

## Boundaries

Changing plan acceptance needs Gate 1 for that change. The consultation set
that kmhn lists (contribution, InfoSec, independent UX) applies. Keep the
existing holds and the G1 to G5 work separate. This record starts no session,
timer or implementation.
