# Review: Claude/Lumo synthesis on principal delegation

The governor-reviewer relayed Lumo's critique of Claude's planner-architect
response to the principal-delegation proposal.

Accepted from Claude:

- AI-authored `principal` fields are self-attestation. An AI cannot verify who
  authorized its own session by writing a field into its own coordination
  message.
- v2.x should be docs-first, not a schema extension, until there is adopter
  evidence and clearer purpose-limitation guidance.
- Cut `voluntary`, `review_status`, D1-D4 delegation taxonomy, principal
  aggregation, and service-principal schema work from any minimum v2.x slice.

Accepted from Lumo:

- Claude's GDPR/immutability argument proves too much if treated as a hard
  blocker. Git already stores personal data. The issue is purpose limitation
  and misuse, not whether personal identifiers can ever appear in the repo.
- Delegation grants should live in the coordination channel, not in commit
  metadata. Commit authorship is already where "AI = human" confusion happens.
- Contestation should be discoverable. A free-text note is too easy to miss.
  A `kind: note` convention with `note_type: contestation` is a better
  docs-first compromise than a new message kind.
- "No adopter evidence" should be documented carefully: this failure mode is
  partly invisible because current workflows do not instrument delegation
  cleanly.

Change made:

- Reframed the proposal around human-authored delegation grants that AI
  sessions reference, rather than AI-authored `principal` assertions.
- Updated the minimum viable shape to use docs-first `kind: note` conventions:
  `note_type: delegation-grant` and `note_type: contestation`.
- Reframed GDPR language as purpose-limitation guidance rather than a schema
  blocker.
- Clarified that v2.x should document the convention and defer schema/tooling
  work until evidence justifies it.

Recommendation:

If planner-architect writes a Gate 1 plan, make it a docs-only slice:

- FAQ entry for AI acting under a human or service account;
- human-authored session-authorization note convention;
- contestation note convention;
- explicit non-goals for AI-authored principal fields, person-level analytics,
  routine review-depth metadata, and schema changes.
