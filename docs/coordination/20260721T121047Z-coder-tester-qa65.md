# Proposed learning: enumerate every release public-truth surface

Records the post-publication discovery that v2.3.0 updated the canonical
adopter changelog but left the repository-root changelog at 2.2.5. The
learning distinguishes verifying selected artifacts from first proving that
the verification set is complete.

The target state is a release truth-surface manifest, validation of every
tracked changelog/version claim or explicit waiver, exact prospective/tagged
archive inspection, and a claim-to-evidence completion matrix. It also records
the immutable recovery rule: retract premature completion and publish a patch;
never move an already published tag.
