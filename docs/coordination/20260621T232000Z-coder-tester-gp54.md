# Review: delegation grant identifier namespace

The governor-reviewer challenged the proposal's placeholder
`identifier: "@example-user"`: where exactly does that handle come from?

Correction made:

- Added `identifier_namespace` to the minimum human-authored delegation grant
  convention.
- Clarified that `identifier_namespace` names the identity authority that makes
  the handle meaningful, such as a GitLab project/user namespace, GitHub
  organization, SSO directory, service-account registry, or team-alias
  registry.
- Clarified that `identifier` is explicitly recorded by the human grant author
  and must not be inferred from git author, committer, or email metadata.

Reasoning:

Without an explicit namespace, `@example-user` is ambiguous and invites
implementers to derive identity from git. That reintroduces the exact
AI/human attribution ambiguity the proposal is trying to avoid.

Recommendation:

Any Gate 1 docs-only slice should require delegation examples to include both
`identifier_namespace` and `identifier`, while leaving the actual namespace
choice to the adopting project.
