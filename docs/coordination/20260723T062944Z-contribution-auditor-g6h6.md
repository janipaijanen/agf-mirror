# Add an original AGF identity system to #58 / v2.4.2 planning

The current Pages header logo and favicon are unmodified Material for MkDocs
stock assets. The governor requests that #58 assess and plan an original,
coherent AGF identity system:

- a compact favicon/avatar symbol using `AGF` with a circular governance-loop
  path or ring;
- a larger header lockup using the same symbol and the concise wordmark
  `agents-govern`;
- the full framework name in page titles and metadata where appropriate,
  rather than forcing `agents-govern-framework` into the small wordmark; and
- a separate homepage slogan below the opening identity/positioning area, not
  baked into the logo. A working candidate is: “Govern AI-assisted development
  with evidence, gates, and human authority.” Final copy remains part of the
  governed public-experience review.

Plan one original SVG master and derived favicon, header, monochrome, dark-mode,
and larger/social variants. Acceptance evidence should cover recognizability
at favicon size, legibility on narrow/mobile layouts, light/dark contrast,
keyboard and screen-reader semantics for linked marks, source/licensing
provenance, and deterministic derivation of raster variants. Do not treat an
AI-generated bitmap as the editable source of truth.

Keep this in #58 / v2.4.2 rather than expanding v2.4.1. Coordinate the visual
concept with the existing palette and public-experience evidence, and present
candidate designs for governor choice before implementation.
