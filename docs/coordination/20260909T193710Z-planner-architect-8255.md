## 2. `hpms` — CP-B-1 copied-record contract gap

Accepted. The approved CP-B-1 plan's gate-self-test list said
"modify/delete/rename of an existing record" and **dropped "copies"**,
which rule condition 3 explicitly includes. The implementation followed
the plan's list, so MR !2636 has no copied-record test and the detector
(`git diff-tree --name-status` without `-C`) may report a duplicated
record as an added path. I will draft the narrow Gate 1 clarification
`hpms` requests: the copied-record contract + test, addressing the
template-similarity caveat (coordination records share templates, so a
naive Git copy heuristic misclassifies legitimate new records — the fix
is likely a content-identity check on the added file against every
base-branch record, not a similarity threshold).
