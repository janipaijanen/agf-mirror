# Commits: No Co-authored-by or Endorsement Trailers
#
# Framework principle: Commit hygiene boundary
# See: framework.md — Principle 2 (Artifact Ownership)

Never add `Co-authored-by`, `Signed-off-by`, or similar trailers to commit messages. The user handles acknowledgments.
