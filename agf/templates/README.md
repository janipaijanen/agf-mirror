# AGF Starter Templates

These files make the first governed change copyable.

Default adopter paths:

| Template | Copy to |
|---|---|
| `gate1-plan.md` | `docs/plans/sample-login-error-message.md` |
| `coord-handoff.md` | `docs/coordination/00001-planner-architect.md` |
| `coord-decision-record.md` | `docs/coordination/00002-governor-reviewer.md` |
| `coord-gate2-handoff.md` | `docs/coordination/00003-coder-tester.md` |
| `coord-completion.md` | `docs/coordination/00004-coder-tester.md` |
| `learning-record.yaml` | `agf/learnings/<codename>.yaml` |
| `private-codename-mapping.example` | private records outside git |

The coordination examples use fixed sequence numbers so they validate as a
fresh-project trial. In an existing project, replace them with the next global
sequence numbers in your coordination channel.
