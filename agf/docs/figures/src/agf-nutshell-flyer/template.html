AGF Agent Governance Framework, in a nutshell
One-page orientation

AGF helps you use an AI coding assistant without losing engineering accountability.

Let the AI do the clerk work. Keep the engineering judgment.

AGF is not an AI model, LLM, or coding assistant — it's files and rules in your repository that work alongside the AI assistants you already use (Claude, Codex, and others).

The problem

An AI assistant can write code faster than you can explain it later. If something breaks in review — or in front of a customer — "the AI did it" is not an answer.

The AGF idea

Split the work into roles, two review gates, and a written decision log — so you can always answer "why did this land, and who accepted it?"

Three players, before anything else

You Decide what's acceptable, approve the plan, judge the evidence, and own the risk. The AI never decides this for you.
Your AI assistant Drafts the plan, edits files, runs commands, writes up the change, and summarizes the evidence for you to read.
Automatic checks Scripts and tests that report pass or fail. They catch mistakes; they never approve anything themselves.

One change, start to finish — who's doing what

Two checkpoints, called Gate 1 and Gate 2: Gate 1 approves the plan before any code is written; Gate 2 approves the finished change before it merges.
